# Mood Ink

Likho, aur ink usi mood mein settle ho jaati hai. Type some text about how you're feeling → Gemini reads the mood → matching emoji + a Giphy GIF show up.

## What's inside

```
mood-detector/
├── server.js          Express backend — calls Gemini + Giphy
├── package.json
├── .env.example        Copy this to .env and fill in your keys
└── public/
    ├── index.html
    ├── style.css
    └── script.js
```

## 1. Install dependencies

```bash
cd mood-detector
npm install
```

## 2. Get a Gemini API key (free)

1. Go to **https://aistudio.google.com/apikey**
2. Sign in with a Google account.
3. Click **Create API key** → choose or create a Google Cloud project when prompted.
4. Copy the key that's generated (starts like `AIzaSy...`).

Gemini has a generous free tier, so this is enough to build and test with — no credit card needed to start.

## 3. Get a Giphy API key (free)

1. Go to **https://developers.giphy.com/**
2. Sign in / create an account → click **Create an App**.
3. Choose the **API** option (not SDK).
4. Once created, copy the **API Key** shown on the app's dashboard.

Giphy's free "Beta" key works fine for development; you can apply for a production key later once you want to launch publicly.

## 4. Configure your environment

```bash
cp .env.example .env
```

Open `.env` and paste your keys:

```
GEMINI_API_KEY=your_actual_gemini_key
GIPHY_API_KEY=your_actual_giphy_key
PORT=3000
```

## 5. Run it

```bash
npm start
```

Open **http://localhost:3000** in your browser, type something about your day, and click "Read the mood."

For auto-restart on file changes during development:

```bash
npm run dev
```

## How it works

1. `POST /api/analyze` receives `{ text }` from the frontend.
2. The backend sends a strict-JSON prompt to Gemini (`gemini-2.5-flash`), asking it to classify the text into one fixed mood category (happy, sad, angry, excited, anxious, calm, love, bored, surprised, tired, confused, grateful, proud, neutral).
3. The mood is mapped locally to an emoji (kept in code, not generated by the model, so it's always consistent).
4. The mood name is used to search Giphy for a matching reaction GIF, and one is picked at random from the top results.
5. Everything (`mood`, `emoji`, `gif`, `reason`) is returned to the frontend and rendered, with the page's accent color shifting to match the detected mood.

## Notes / things you may want to extend

- **Rate limiting / abuse protection**: there's none right now — add something like `express-rate-limit` before deploying publicly, since each request costs a Gemini + Giphy call.
- **Language**: the Gemini prompt explicitly handles English, Hindi, and Hinglish input.
- **Mood set**: the 14 moods in `server.js` (`MOOD_EMOJI_MAP`) are intentionally fixed so the UI and color mapping stay predictable — add more by extending that map, the matching `MOOD_COLORS` in `public/script.js`, and the `VALID_MOODS` list will follow automatically.
- **Model name**: uses `gemini-2.5-flash`. If Google renames or deprecates it later, swap `GEMINI_MODEL` in `server.js`.
- **Never commit `.env`** — it holds your real API keys. `.env.example` is safe to commit; `.env` is not.
